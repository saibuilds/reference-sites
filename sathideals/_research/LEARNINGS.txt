1.  THE IMPLEMENTATION VERDICT (free/cheap, own the code, no headaches)
--------------------------------------------------------------------------------

Build phase  — $0 new spend.
  Claude Code Max (already owned) builds custom Next.js/static pages.
  Free libs: shadcn, Magic UI, GSAP, Lenis, Motion, Spline free,
  Hunyuan 3D free (20/day), Cloudflare free deploy.

Media phase  — at most ~$33/mo total.
  Google AI Pro ($19.99) for Veo video + Nano Banana Pro images
  CapCut Pro (~$13) for editing real footage.
  Skip Higgsfield/Artlist/Framer/Lovable/Runway subscriptions.

The Runable unlock — the cheap-media closer.
  Runable (runable.com, phone/browser app, ~$1 trial) produces
  1600x1000 3D-style product images on white + animates them to short
  hero videos. That's EXACTLY our hero spec. The workflow:
       Runable on phone -> download -> commit to assets/<id>-hero.{jpg,mp4}
       -> build auto-consumes via resolveAsset()/resolveVideo()
       -> Cloudflare deploys, GHL wires the lead form.
  Do NOT host the sites on *.runable.site — that's platform-locked and
  loses code ownership, GHL/RESO wiring, custom-domain control.

4.  AUTO-SYNC BETWEEN COMPUTERS
--------------------------------------------------------------------------------

.claude/settings.json (now git-tracked) runs a SessionStart hook on every
Claude Code session start:
   git fetch origin && git pull --rebase --autostash origin <current-branch>
Prints one of:
   "auto-sync: up to date on <branch>"
   "auto-sync: pulled latest on <branch>"
   "auto-sync FAILED on <branch> - resolve manually"

Autostash protects any in-progress edits.  If a rebase conflicts, you
resolve it manually — never silent data loss.

To bootstrap a brand-new machine:
   git clone https://github.com/saibuilds/reference-sites.git
   cd reference-sites
   git checkout claude/setup-mcp-api-keys-t4GTr
   # set env vars per .mcp.env.example  (or paste them into
   # Claude Code on the web -> Environment -> Variables)
   claude          # then say: read BOOTSTRAP.md
The SessionStart hook then keeps both machines current automatically.

5.  THE ORIGINAL DESIGN PRINCIPLES THAT MATTER MOST
--------------------------------------------------------------------------------

(From notes/session-learnings.md + ARSENAL.md, captured for quick recall.)

Taste > AI.  AI just makes execution fast.  The differentiator is
attention control: one focal point per screen, one job per section,
whitespace = luxury (default to 2x what feels right), motion guides
the eye instead of decorating.

Build flow (under ~1 hour per page):
   Reference (10m) -> Direction (5m) -> Attention map (5m) ->
   Generate (15m) -> Refine (30m) -> Polish (15m).

Premium-site sections that earn their keep:
   Hero (one focal point) -> Trust (logos/awards/years) -> Proof
   (work/portfolio) -> Process -> Social proof -> CTA.
   Before/after slider: huge for reno + real estate.

Never ship invented business facts.  Use clearly-marked [PLACEHOLDER]s
until real content arrives.  This is what triggered the earlier
rollback — don't repeat it.
